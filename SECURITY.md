# Security and Privacy

## Public repository warning

Assume every committed file, issue, pull request, workflow log, and GitHub Pages artifact is public.

Never commit:

- transcripts or recordings from church interviews;
- personal contact information not already approved for publication;
- counseling, benevolence, prayer, child-safety, or pastoral-care details;
- passwords, tokens, API keys, DNS or hosting credentials;
- private analytics or donor/giving information;
- internal theological, staffing, or governance disagreements;
- unapproved photographs or stories involving identifiable people.

Use a separate private repository for each church project.

## Reporting

Do not open a public issue containing sensitive information. Contact the repository owner privately through the security contact configured when the GitHub repository is created.
