# Sources

Store immutable or clearly versioned source material here:

- interview transcripts;
- supplied church documents;
- existing website copy and captures;
- approved policies;
- analytics exports;
- brand and media assets;
- integration and account inventories without credentials.

Do not edit raw transcripts to make them cleaner. Create corrected or processed derivatives separately and preserve the original source.

Mark sensitive material and limit repository access appropriately.
